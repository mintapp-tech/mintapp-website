# Mintapp Brand Asset Pack

## Included
- `mintapp-logo-primary.svg` — primary horizontal logo
- `mintapp-logo-white.svg` — reversed logo for dark backgrounds
- `mintapp-logo-mono.svg` — one-color logo
- `mintapp-logo-stacked.svg` — stacked lockup
- `mintapp-logo-bilingual.svg` — English + Arabic lockup
- `mintapp-symbol-color.svg` — standalone M symbol
- `mintapp-symbol-mono.svg` — monochrome M symbol
- `mintapp-symbol-white.svg` — white M symbol
- `mintapp-app-icon.svg` — square app/social icon
- `mintapp-favicon.svg` — compact favicon source
- PNG exports in multiple resolutions
- `favicon.ico`
- brand color tokens in CSS and JSON

## Type
English wordmark: Manrope (recommended)
Arabic: Alexandria (recommended)

The SVG files keep text editable in Figma where possible. If your system does not have the font installed, Figma may substitute it until you select Manrope/Alexandria.

## Core colors
- Signature Mint — #32E6A6
- Deep Mint — #0A6B50
- Dark Forest — #071B16
- Canvas — #F7F8F4
- Digital Accent — #6C63F5

## Figma
Drag the SVG files directly into a Figma canvas. The standalone symbol assets are pure vector geometry and can be edited without any font dependency.
